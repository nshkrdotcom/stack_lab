# StackLab Toy Document Review

Deterministic Phase 4 proof app for the generic binding substrate.

The example owns a local document-review product pack and a supervised local
HTTP-shaped fixture connector. Its tests prove the pack compiles through the
Mezzanine PackCompiler, activates durable ConfigRegistry binding records,
resolves operations through Jido manifest lookup, authorizes through Citadel,
materializes credential leases, crosses the BindingResolver envelope, invokes
the local connector, and produces lower and substrate receipt shapes without
Extravaganza provider nouns.
