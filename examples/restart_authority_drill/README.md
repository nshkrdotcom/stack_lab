# Restart Authority Drill

Restart and timing drill for the assembled lower seam.

Covered cases:

- delayed remote acceptance
- replay recovery after replacing the remote Spine node
- revoked credentials after restart
- expired leases after restart
- rotated handle epochs after restart
- stale installation revisions after restart
- stale target grants after restart
- duplicate dispatch old lease materialization rejection
- delayed retry authority revalidation
- target detach, sandbox restart, process crash, stream reconnect, and
  workflow resume revalidation
