# StackLab TRINITY Single-Node Roundtrip

Standalone TRINITY single-node proof over the `trinity_framework` package. The
example uses the mock-tiny runtime profile, local trace output, and mock provider
dispatch; it has no AppKit, Jido, Mezzanine, OuterBrain, or Citadel runtime
dependency.

The opt-in `:qwen_sakana_adapted` test uses the canonical adapted artifact when
`TRINITY_ARTIFACT_DIR` is set.
